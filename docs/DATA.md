# Benchmark data and preprocessing

Raw benchmark data are loaded from version-pinned R packages; this repository
does not redistribute separate raw-data downloads. See `software-versions.csv`
for versions and the package documentation for original data references and terms.

| Benchmark | Package data | Predictors | Evaluation label |
|---|---|---|---|
| Biopsy | `MASS::biopsy` | Columns 2--10: nine cytological scores | `class`, K=2 |
| AIS | `sn::ais` | RCC, WCC, Hc, Hg, Fe, BMI, SSF, Bfat, LBM, Ht, Wt | sex, K=2 |
| Wine | `gclus::wine` | Thirteen chemical variables (all except Class) | Class, K=3 |
| Banknote | `mclust::banknote` | Six measurements (all except Status) | Status, K=2 |

`Section5_Datasets.R` and `CalFlex_FormalLib.R` are the authoritative loaders.
Biopsy removes incomplete source rows before standardizing its predictors.
AIS and Wine standardize selected predictors, then apply the loader's complete-case
and nonmissing-label filter. Banknote standardizes its six measurements.
Repeated profiles remain separate subjects; no deduplication or jitter is applied.
Class labels are used for evaluation, not as initialization labels.

For the semi-real arm, each standardized cell is independently selected with
probability .05 and receives additive N(0,5^2) noise. The perturbed data are not
standardized again. Every method receives the same perturbed copy within a
replicate. Clean labels and the prespecified K remain fixed.

Simulated data are generated by the formal truth libraries and semantic RNG
streams. They are regenerated on demand rather than stored as a second raw-data
collection. Full truth and fit provenance is retained in the aggregate RDS files.
